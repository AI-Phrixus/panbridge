PanBridge 隱私與資料使用說明

更新日期：2026-09-30。PanBridge 是由帳號持有人自建、自用的網盤搬運工具；只有通過本站登入的人可以操作。聯絡：phrixusbowyer@gmail.com。

使用目的與權限

本站依使用者指示，下載夸克／百度分享文件，並上傳到使用者選擇的網盤。Google Drive 僅申請 drive.file 權限，處理本站建立或使用者明確授權給本站的文件；不申請整個雲盤的任意存取權。本站讀取 Google 回傳的帳號識別碼與信箱，用於防止任務意外交付到其他帳號，以及顯示連線狀態；讀取配額、文件與資料夾中繼資料，用於路徑管理、容量檢查和交付驗證。

保存與傳輸

OAuth 用戶端密鑰、存取及續期憑證加密保存在使用者的 Oracle 伺服器，不寫入公開原始碼。上傳續傳憑證亦加密保存。文件搬運時會在該伺服器暫存下載內容，經確認上傳完成後清理。任務清單、文件名、大小、路徑及交付識別碼保存在伺服器資料庫；應用程式沒有另行加密整個暫存文件或整份任務資料庫。

資料透過 HTTPS 傳送至使用者指定的雲端服務；網站 HTTPS 由 Cloudflare Tunnel 提供。本站不出售資料、不用於廣告、不建立公開文件分享，不將 Google 憑證放入播放器連結。Google API 資料的使用遵守 Google API Services User Data Policy，包括其適用的 Limited Use 要求。

暫停、移除與撤銷

暫停會保留已驗證的下載和上傳續傳資料。刪除任務目前是軟刪除：停止工作並從列表隱藏，保留文件紀錄與未完成暫存；不刪除已交付的雲端文件，備份亦不立即清除。若需清理暫存、任務資料或備份，請由伺服器持有人確認後執行；雲端文件可在對應網盤自行移至垃圾桶。

在帳號設定中斷開 Google Drive，會移除本站保存的 Google 使用者授權憑證，但不刪除已交付文件或 OAuth 應用程式用戶端設定。也可到 Google 帳號的第三方連線管理 撤銷 PanBridge 授權。憑證不會用於未經使用者授權的用途。
