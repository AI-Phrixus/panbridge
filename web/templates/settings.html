pCloud — 推荐：粘贴 auth token（适合开了 2FA）

网页能登录但密码+验证码 API 失败时用此法。步骤：① 浏览器打开 my.pcloud.com 并登录 ② 按 F12 → Network（网络）③ 刷新页面 ④ 点任意发往 api.pcloud.com / eapi.pcloud.com 的请求 ⑤ 在 URL 或 Form Data 里找到 auth= 后面那一长串，复制整段 token 粘贴下方。
