# 大檔下載：夸克 vs 百度 · 策略說明

> 適用 VPS 中繼（如 Oracle 亞太）。**不是**官方雲對雲秒傳。

---

## 結論（怎麼選）

| 場景 | 推薦 | 原因 |
|------|------|------|
| **能選源站時** | **優先夸克** | 海外 VPS 限速通常輕於百度；多連線 Range 較容易吃滿 |
| **只有百度分享** | 百度可用 | 能跑完+續傳；海外非 SVIP **往往很慢**（數十～數百 KB/s 常見） |
| **百度 SVIP + 國內線路** | 百度可很快 | 與帳號/線路強相關，本工具不保證 |
| **>10GB 目標盤** | 務必 OneDrive 等大容量 | 與源站無關；pCloud 免費空間常不夠 |

**一句話**：同樣大檔、海外 VPS 中繼，**夸克一般更快更穩**；百度勝在資源多，但限速是常態。

---

## 為什麼夸克往往更快？

1. **限速策略不同**：百度對非會員/海外 IP 限速很兇；夸克相對寬鬆（仍可能變）。  
2. **直鏈 CDN**：夸克直鏈對多 Range 並行較友好。  
3. **百度 403**：多連線易被拒，過去常被迫單線程；v0.3.7+ 會**先試多連線，403 再回退單線**。

## 為什麼百度仍然有價值？

- 資源覆蓋廣，很多片源只有百度。  
- 本工具已處理：轉存、LogStatistic UA、直鏈刷新、斷點續傳、看門狗。  
- **慢但能掛機跑完** 就是設計目標之一。

---

## v0.3.7 速度策略（實作）

1. **單檔多連線 Range，寫入同一個 `.part`**（不佔雙倍磁碟裝 segments）  
2. **百度默認嘗試 4 連線**（`BAIDU_DOWNLOAD_CONNECTIONS`），失敗自動單線  
3. **夸克/通用默認 6 連線**（`DOWNLOAD_CONNECTIONS`）  
4. 直鏈過期仍可刷新後續傳  
5. 已有連續前綴（例如已下 2GB）時，**只對剩餘區間並行**

### 環境變量

```env
DOWNLOAD_CONNECTIONS=6
BAIDU_DOWNLOAD_CONNECTIONS=4
DOWNLOAD_CHUNK_SIZE=1048576
```

小 VPS（1GB RAM）建議百度連線 ≤4，避免記憶體/連線打滿。

---

## 你能做的非代碼加速

1. **同一資源若有夸克鏈，改下夸克**  
2. 百度帳號 **SVIP**（效果因地區而異）  
3. VPS 選 **日/港/新** 等亞太（已在大阪則合理）  
4. 不要同時開第二個超大檔（磁碟與帶寬競爭）  
5. 少重啟服務（每次斷流重連有代價）

## 現實預期

| 源 | 海外 VPS 粗量級（經驗，非承諾） |
|----|----------------------------------|
| 百度非 SVIP | 50–200 KB/s 很常見 → 25GB 可能要數天 |
| 夸克 | 常可到數百 KB/s～數 MB/s（看當日與 CDN） |
| 多連線成功時 | 相對單線可有 **1.5×～4×** 提升（上限仍受帳號/CDN 限速） |
