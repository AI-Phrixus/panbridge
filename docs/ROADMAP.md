更新：2026-10-03。當前項目為 Google Drive 搬運；OneDrive 僅保留歷史相容碼與記錄，不再列為待開發目標。

## 已實作與發布的基線

| 能力 | 完成界限 |
|---|---|
| 私人 Google Drive 交付 | 最小 drive.file 授權、帳號綁定、加密憑證、分塊續傳與遠端 ID／大小檢查 |
| 下載／上傳流水線 | 有界預取3件、64 GiB 控制預算、2 GiB安全留量；上下行各1，跨任務共用 |
| 連線池與 Range | 單檔共用連線池、隔離 Cookie、直接寫入 .part、不額外拼接完整副本 |
| 任務操作 | 搜尋選檔、跨頁選取、暫停／繼續、頁面內確認、軟刪除、防重複建立 |
| 新項目列表 | 顯示從1開始，API／資料庫仍用內部ID；不重新下載或抹去來源證據 |
| 原 HTTPS／WARP | 2026-10-02 實測正常；workers.dev 候選入口未完成遷移，不作為使用入口 |
| 設定頁 UI 3 | 安全請求、純文字回饋、防重複、可停止串行掃碼、繁體與可訪問性補齊。部署證據見 UI3_REVIEW／STATUS |

## 後續增量

只在現有資料安全與驗收門檻通過後，考慮更準確的ETA、停滯分類、交付報告匯出與可撤回歷史任務檢視。先提供可用小增量，依實際反饋修正，不承諾突破來源服務限速。

2026-10-03不再定時檢查。2026-10-04 00:00日本時間起每3小時檢查一次，只通知完成或需要處理的變化；Oracle搬運不因此停止。監控不包含A1、DNS／VPN／OAuth變更、新增下載或反覆重試。

## 不可妥協條件

1. 不改任務ID或覆蓋DB來讓列表從頭開始；沒有備份證據不得清理。
2. 雲端帳號、交付ID或大小不符，不標記完成；完整哈希校驗不能用抽查代替。
3. 部署先保存精確程式復原點；UI-only不重啟下載服務，復原不還原已更新DB。
4. 密鑰、Cookie、token和整份SQLite不得進入公開記錄／Git。
5. OneDrive v0.4.x歷史成果留在STATUS與舊發布記錄，不誤當目前Google播放器驗收。
